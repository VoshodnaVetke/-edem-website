# Проверки очистки атласа

Установка: `python -m pip install -r tests/design-system/requirements.txt`.
Нужен Chromium и его системные библиотеки. При использовании Playwright:
`python -m playwright install --with-deps chromium`.
Передать путь к браузеру через `--chromium`. Результаты сохраняются в `work/atlas-check/`.

- `check_css.py` сравнивает активный CSS очищенного атласа с неизменяемым HTML в `design-system/reference/`. Проверяет 40 комбинаций ширины, устройства, motion и состояния; при любом необъяснённом расхождении завершается с ошибкой.
- `check_navigation.py` сравнивает раскладку и открытые диалоги Navigation C при 390/768/1280 px.
- `check_runtime.py` загружает реальные HTML/CSS/JS через перехват локальных URL. Проверяет 37 образцов, поиск, фильтры, копирование, iframe навигации, ошибки JavaScript и горизонтальное переполнение при 390 и 1280 px.

Сеть для страниц заблокирована. В runtime используется встроенный SVG fallback. Проверки внешних шрифтов, Rough.js и WebGL с CDN требуют отдельного прогона.

Единственное исключение сравнения: при reduced motion у двух декоративных индикаторов отменена вращающая анимация; исходная identity matrix и новое отсутствие transform визуально совпадают. Новое отключение движения проверяется как намеренное исправление, а не маскируется общим допуском.
