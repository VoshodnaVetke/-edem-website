# @edem/ui

React + TypeScript библиотека интерфейсов ЭДЕМ. Содержит 24 компонента, три геометрии рамок, четыре круговых загрузчика и линейную передачу данных. [Каталог](../../apps/catalog) показывает 37 актуальных образцов.

## Подключение

```tsx
import { Button, Card, Heading, Text } from "@edem/ui";
import "@edem/ui/styles.css";
import "@edem/ui/fonts.css";

<Card frame="double">
  <Heading level={3}>Заголовок</Heading>
  <Text>Содержимое приложения.</Text>
  <Button onClick={handleAction}>Действие</Button>
</Card>;
```

React 18.3 или 19 и React DOM устанавливает потребитель. CSS подключается явно один раз. `fonts.css` необязателен: приложение может подключить собственные локальные Tektur, Onest и Anonymous Pro, задав `--font-display`, `--font-body`, `--font-mono`. В поставляемом CSS variable-font семейства называются `Tektur Variable` и `Onest Variable`; Anonymous Pro — обычное семейство. Все woff2 включены в сборку; Google Fonts/CDN не нужны.

Экспорты пакета: `@edem/ui` (ESM + TypeScript declarations), `@edem/ui/styles.css`, `@edem/ui/tokens.css` и `@edem/ui/fonts.css`. `styles.css` уже содержит токены. Пакет поддерживает tree shaking; Three.js вынесен в динамический модуль для WebGL.

Сборка: `npm run build -w @edem/ui`. Для установки в другом проекте использовать архив `npm pack -w @edem/ui`. В npm пакет пока не опубликован. Код не снабжён открытой лицензией (`UNLICENSED`); лицензии включённых шрифтов лежат в `dist/licenses`.

## API

Компоненты принимают обычные HTML-атрибуты, `className` и `style`. Состояния и данные контролирует приложение. Ни один компонент не запускает фиктивную операцию или автоматическое подтверждение успеха.

### Поиск и маршрутизация

```tsx
import { Navigation, type SearchResult } from "@edem/ui";

const search = async (
  query: string,
  signal: AbortSignal,
): Promise<SearchResult[]> => {
  const response = await fetch(`/api/search?q=${encodeURIComponent(query)}`, {
    signal,
  });
  if (!response.ok) throw new Error("Search failed");
  return response.json();
};

<Navigation
  brand="ЭДЕМ"
  items={[{ label: "Игры", href: "/games" }]}
  bottomItems={[{ label: "Афиша", href: "/events" }]}
  account={{ label: "Кабинет", href: "/account" }}
  currentHref="/games"
  onSearch={search}
/>;
```

Поиск имеет debounce 180ms, отменяет старые запросы и игнорирует устаревшие ответы. Без `onSearch` кнопки поиска нет. Пакет не подключает роутер и не подменяет историю браузера. Ссылки остаются обычными anchor; приложение может адаптировать переходы через свой роутер и обработчик кликов.

Меню и поиск закрываются по Escape и кнопке, блокируют фон через native dialog и возвращают фокус кнопке открытия. Предварительный статус паттерна Navigation C сохранён; наличие API не означает окончательного утверждения информационной архитектуры сайта.

## Единый ручной контур и подложки

`src/Sketch.tsx` содержит единственные настройки Rough.js для контуров, детерминированную неровную подложку `SketchSurface` и измеряемую панель `SketchPlate`. Их оформление находится в `styles/sketch.css`. Карточки, кнопки, поля, диалоги и акцент используют эти общие примитивы. Подложка намеренно слегка выходит за линию; нативные прямоугольные фоны у элементов управления прозрачны.

Цвет контура задаётся через `--edem-sketch-ink`, цвет подложки — через `--edem-surface-fill`. Состояния меняют только эти параметры. Поле получает голубой существующий контур через focus-within, без второй CSS-рамки. Белая и голубая части вертикального акцента отрисованы из одной геометрии пути; голубой участок точно совпадает с белым.

Дерево хранится только в `assets/tree.svg`: это приложенный владельцем исходник, без реконструкции координат. SVG-режим показывает одно изображение, WebGL использует тот же SVG как текстуру. Копий координат и трёх цветных SVG-дублей нет.

DATA LOSS содержит тонкие чередующиеся сегменты, градиентную линию, светящийся маркер, нижнюю пакетную шкалу и сканирование. `value` остаётся управляемым. Дополнительная декоративная шкала принимает CSS-переменную `--edem-packet-progress` (по умолчанию равна основному проценту). Только демонстрация каталога запускает исходный цикл 4,2 секунды: основная линия движется по smoothstep, нижняя шкала — линейно. При reduced motion убраны помехи, импульсы и сканирование.

`npm run check:css` проверяет исходники CSS: запрещены приоритетные флаги и повторные объявления одного свойства одного селектора в одинаковом условном контексте. Общие правила следует редактировать на месте, а не дописывать исправляющий каскад.

## Визуальные правила

- Фон `#05070C`, поверхность `#141923`, текст `#EAF0FA`, белый контур `#FFFFFF`, циан `#25F4FF`, фиолетовый `#BC5CFF`, успех `#7CE7C1`, ошибка `#FF8295`.
- Tektur 700 — заголовки и действия; Onest 450 — содержательный текст; Anonymous Pro — системные подписи.
- H1: 30/40/56 px, H2: 25/30/36, H3: 20/21/22; body: 16/17/17, reading: 17/17/18 на телефоне/планшете/десктопе. Значения заданы в rem.
- Внешняя сетка: 4 колонки до 650px, 8 от 651 до 1023px, 12 от 1024px. Галерея использует auto-fit, внутренности карточки — Container Queries.
- Обычная кнопка тёмная с белым контуром. Выбранная — циановая с белым контуром. Hover/focus-visible — фиолетовая с циановым контуром и тёмным текстом.
- Карточка-ссылка сохраняет тёмную заливку. Mouse-hover даёт подъём на 4px и циановое свечение; клавиатура — заметную подсветку; touch — краткую реакцию на нажатие без desktop-hover.
- Рамки отрисовываются заранее при приближении к viewport (~240px), однократно; основной контур — 4.3s на desktop и 1.35s на touch. При reduced motion нет прорисовки и декоративного движения.
- Содержимое не помещается в фиксированную высоту и не перекрывается декоративными слоями. Значимые статусы сопровождаются текстом, не одним цветом.
- Локальные эффекты карточек расположены под содержимым. Редкая помеха работает только в видимой карточке и прекращается во время чтения/фокуса. Все необязательные CSS-анимации отключены при reduced motion.
- Шрифты и CSS подключаются явно: пакет не меняет body приложения и не добавляет глобальных обработчиков кнопок. Переменные `:root` и классы с префиксом `edem-` — публичная поверхность CSS.

## Статусы и полнота

Каталог содержит 37 образцов: 6 основ, 9 карточек, 5 кнопочных образцов, 4 управления, 5 загрузок, 4 деталей, 1 навигацию и 3 сетки. 33 образца approved, 4 preliminary: Navigation C и три дополнительных образца семейства/размеров/асинхронных состояний кнопок. Их статус отмечен в каталоге; он не менялся автоматически при переносе в React.

Реализация и документация пакета — текущий источник правил. Отдельных старых HTML-эталонов, архивных дизайн-спецификаций и параллельных описаний в рабочей версии больше нет.

## Проверки

`npm run check` из корня запускает типы, unit/SSR-проверки, сборку пакета/каталога и браузерные тесты. Проверяются реальные ссылки, состояния, отмена поиска, очистка подписок, клавиатура, touch, reduced motion, локальные кириллические шрифты, 11 ширин и автоматический WCAG A/AA. Каталог работает без внешней сети. WebGL имеет SVG fallback; доступность GPU зависит от среды приложения.
