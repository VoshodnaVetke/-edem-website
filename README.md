# Эдем | Официальный сайт мастерской группы

«Эдем» — мастерская группа, которая разрабатывает и проводит авторские ролевые игры и развивает собственную вселенную.

## Задачи сайта
- Представить мастерскую группу и её игры.
- Публиковать афишу предстоящих мероприятий и принимать заявки на участие.
- Вести архив проведённых игр с фотогалереями.
- Публиковать отзывы с разрешения участников.
- Развивать публичную энциклопедию вселенной.
- Предоставлять личный кабинет с заявками и статусами участия.

## Разделы
- **Главная** — о мастерской, ближайшие игры, отзывы и контакты.
- **Наши игры** — архив, карточки и фотографии.
- **Афиша** — расписание, анонсы и запись.
- **Энциклопедия** — публичные статьи и раскрываемые спойлеры.
- **Личный кабинет** — профиль и заявки.

Графический язык утверждён в v50. Актуальная версия v55 включает мобильные исправления (раннюю прорисовку, отсутствие ложного hover на касание) и новую типографическую схему: **Tektur** для заголовков, **Onest** для обычного текста, **Anonymous Pro** для технической телеметрии. Все разные варианты загрузки v50 сохранены. Прототип — **демонстрация дизайн-системы, не готовая главная страница**.

## Текущий этап
Дизайн-система v55 актуальна. Далее — UX-сценарии и проектирование реальных страниц на её основе. Реализация сайта ещё не началась.
