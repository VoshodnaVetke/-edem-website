# ЭДЕМ · очищенный Component Atlas v10.4

Инженерная подготовка исходника **до переноса в React**. Здесь остаётся демонстрационный атлас: 37 образцов (33 approved, 4 preliminary), а не готовые компоненты сайта. Графика v55, цветовая система и состояния не переосмысливаются.

## Запуск

Из корня репозитория:

```sh
python -m http.server 8000
```

Открыть `http://localhost:8000/design-system/prototypes/components/atlas-clean/`.
Использовать HTTP: навигация загружается отдельным документом того же origin.

## Структура

- `index.html` — образцы и документация; заголовок v10.4 и исправленная ссылка на общий код рамок.
- `css/index.css` — порядок подключения модулей. Порядок входит в каскад.
- `css/01-foundations.css` — основа и геометрия.
- `css/02-card-effects.css`, `03-terminal.css`, `04-details.css`, `05-loaders.css` — эффекты и детали.
- `css/06-responsive.css`, `07-typography.css`, `08-states.css`, `09-reading.css` — адаптивность, типографика и состояния.
- `css/10-atlas.css`, `11-buttons.css`, `12-documentation.css`, `13-link-card.css`, `14-accessibility.css` — оболочка каталога и уточнения взаимодействий.
- `js/` — именованные исходники вместо 16 встроенных скриптов.
- `navigation.html`, `css/navigation.css`, `js/navigation-1.js` — читаемый Navigation C v1.2 вместо base64. Его статус остаётся preliminary.
- `../../../reference/component-atlas-v10.4.html` — неизменяемая загруженная пользователем точка сравнения. Исторические v50–v55 не изменены.

## Что очищено

В активном CSS атласа и навигации **нет `!important`**: исходные 551 + 12 вхождений устранены через разрешение конфликтов, а не усиление селекторов. Убраны 274 перекрытых объявления и четыре неиспользуемые анимации. Повторные правила одинаковых селекторов в одинаковом условном контексте объединены; соседние одинаковые тела сгруппированы. Исходники отформатированы Prettier 3.6.2.

Два приоритета внутри keyframes делали объявления недействительными. Они удалены целиком: простое снятие приоритета включало бы неработавшие ранее значения. Также убраны анимируемые свойства, которые исходный приоритет полностью подавлял. Декоративные анимации включаются только при `prefers-reduced-motion: no-preference`. Исходные вечные анимации двух индикаторов при reduced motion остановлены; это намеренное исправление доступности.

Кнопки копирования исключены из общего семейства продуктовых кнопок и получили собственные явные состояния. У сложного селектора исключений панели снижена непреднамеренная специфичность через `:where()`. SVG-геометрия, цвета, desktop-hover и клавиатурная подсветка сохранены.

## Проверки

```sh
python -m venv .venv
.venv/bin/pip install -r tests/design-system/requirements.txt
.venv/bin/python -m playwright install chromium
# Указать путь установленного Chromium; /usr/bin/chromium подходит для системного браузера.
.venv/bin/python tests/design-system/check_css.py --chromium /usr/bin/chromium
.venv/bin/python tests/design-system/check_runtime.py --chromium /usr/bin/chromium
```

`check_css.py` сравнивает 939 элементов и их `::before`/`::after` с исходником: 320/390/768/1280 px, touch и mouse, reduced motion и обычное движение, десять состояний — всего 40 сценариев. Для исчерпывающего сравнения CSS псевдоклассы заменяются эквивалентными по специфичности тестовыми атрибутами. Это стресс-проверка каскада; реальные клики проверяются отдельно в `check_runtime.py`.

Проверка выполняется без внешних ресурсов. Она не доказывает идентичность CDN-рендеринга Rough.js, WebGL, веб-шрифтов и внешней glitch-библиотеки. Внешние зависимости пока сохранены, включая штатные fallback. Синхронизация всех JS-выдержек документации и превращение примеров в автономные React-компоненты относятся к следующему этапу.
