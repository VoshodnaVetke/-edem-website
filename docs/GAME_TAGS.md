# ЭДЕМ | Библиотека тегов и параметров игр

**Версия:** 1.3  
**Зафиксировано:** 18.11.2026  
**Область применения:** каталог игр, афиша, подробные страницы игр и редактор игр.

Это согласованный справочник **названий и цветов**. Цвета тегов берутся из палитры Neon City, могут повторяться между категориями, но закрепляются за конкретным значением. Файл является спецификацией; внедрение тегов в код сайта выполняется отдельно.

## 10. Игровой акцент: три шкалы

Шкалы **не являются тегами «Механики»** и остаются обязательными характеристиками игры.

| Шкала | HEX | Минимум | Максимум |
| --- | --- | ---: | ---: |
| Социалка | `#BC5CFF` | 0 | 5 |
| Боёвка | `#FF5A00` | 0 | 5 |
| Механики | `#25F4FF` | 0 | 5 |

**Обязательное ограничение:** `социалка + боёвка + механики = 10`. Каждая оценка — целое число от 0 до 5. Все три шкалы имеют по пять делений. Оценки характеризуют **относительное распределение акцентов**, а не абсолютное количество контента.

## Правила отображения и разработки

1. Единый источник данных: не дублировать списки и цвета по страницам.
2. У тегов угловатая неровная рамка, заливка её цветом с непрозрачностью 10% и текст прописными буквами.
3. Цвет может повторяться между категориями. При повторном использовании того же тега сохранять тот же цвет.
4. Проверять контраст и доступность; категория и значение не должны определяться одним лишь цветом.
5. Не публиковать скрытые фракции, сюжетные секреты и спойлерные теги автоматически. Публичность конкретного тега определяется отдельно для каждой игры.
6. Не создавать игровые циклы как категорию: их пока нет.
7. Дату, продолжительность и точное число игроков хранить как структурированные значения, а не выдуманные тематические теги.
8. Общие компоненты и цветовые токены для UI реализовывать в `packages/ui` с сохранением действующей архитектуры. Этот файл фиксирует решения, но **сам по себе не добавляет компоненты, фильтры или страницы**.

**Состав v1.3:** 4 типа игры + 4 вида ролей + 7 локаций + 7 тем + 3 диапазона игроков + 4 возраста + 2 уровня опыта + 3 способа проведения + 6 статусов = **40 значений**, отдельно **3 шкалы акцента**.
