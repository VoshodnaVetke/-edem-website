# Архитектурные решения «Эдема»

- Единый сайт: главная, архив игр, афиша, энциклопедия, личный кабинет.
- Фотогалереи с превью и ссылками на Google Drive.
- Публичная энциклопедия с предупреждениями о спойлерах, без персональных уровней знаний персонажей.
- Мастерские секреты не публикуются.
- Личный кабинет: регистрация, заявки на игры и статусы участия.
- Исходный код публичный; закрытые материалы и секреты не включать.

## React-библиотека

Компоненты интерфейса реализованы в `packages/ui`, актуальные API и правила находятся в README пакета. Каталог React-примеров — `apps/catalog`. Прежние HTML-прототипы и отдельные дизайн-спецификации удалены из рабочей версии по решению владельца.

Каркас публичного сайта — `apps/site` на Next.js App Router и TypeScript, отдельный от `apps/catalog`. CMS, БД, авторизация и хостинг требуют отдельного выбора.

## Базовая компоновка сайта (шаг 3)

- `@edem/ui` — единый источник палитры, шрифтов, геометрии, типографики, сетки и компонентов.
- `apps/site/app/globals.css` содержит только базовые правила документа и доступности; единственный собственный токен ритма секций — `--edem-site-section-space`, без копирования системных токенов или повторения библиотечного breakpoint.
- Секции используют общий ритм из `apps/site/styles/page-layout.module.css`, `--edem-card-gap` и `Layout` из библиотеки; конкретные секции сохраняют собственные CSS Modules.
- На всех страницах одна ссылка пропуска навигации и один основной landmark с `id="main-content"`; мобильная адаптивность и клавиатура проверяются отдельно.
- Figma используется как карта компонентов и маршрутов, не как источник токенов или точной геометрии.

## Контроль CSS и тестирование

- Не использовать `!important` ни в одном исходном CSS-файле: библиотеки, каталога или сайта.
- `npm run check:css` проверяет все исходные CSS обоих приложений и UI, запрещает дубли объявлений в одном контексте и переопределение системных токенов на `:root` приложений; CSS Modules анализируются в отдельных областях видимости.
- Playwright использует единую базовую конфигурацию `playwright.shared.ts`; конфигурации каталога и сайта задают только собственный сервер, набор тестов и репортёр.

## Общая оболочка сайта (шаг 4)

- Утверждённая `Navigation C` из `@edem/ui` используется как единая реализация шапки, меню и мобильной навигации. Не создавать параллельную версию навигации на уровне сайта.
- Подвал `SiteFooter` составлен из существующих компонентов UI; общие шапка и подвал включены один раз в root layout Next.js.
- Действующие маршруты берутся из `apps/site/config/navigation.ts`; не вводить неработающие ссылки или фиктивные действия, пока нет соответствующих страниц и серверной логики.
- Навигация остаётся готовой для desktop и mobile, но поиск отключён, пока нет реального поискового сервиса и содержимого. Временные демонстрационные маршруты и экраны удалены; тесты работают с настоящими компонентами сайта.

## Утверждённое мобильное поведение Navigation C v1.2

- На телефоне (ширина до 650 CSS px) нижняя навигационная панель **фиксирована у нижней границы видимой области экрана** и видна без предварительной прокрутки. При прокрутке она остаётся на месте.
- Панель учитывает нижний safe-area inset мобильного браузера. Страница резервирует место снизу, чтобы подвал и последний текстовый блок не перекрывались навигацией.
- Утверждённая целевая структура панели: **Афиша / Мир / Энциклопедия**, со значками календаря, глобуса и книги. Бургер, поиск и кабинет остаются в верхней шапке. Не подменять этот принцип одним только бургером.
- В текущем публичном приложении в навигацию передаются исключительно существующие маршруты. Три целевые вкладки подключаются по мере появления соответствующих реальных страниц. Демонстрационные HTML-файлы и фиктивные переходы в репозиторий не добавлять.
- Для просмотра в чате: высота iframe должна занимать **оставшуюся доступную высоту viewport**, а не фиксированные 844 px ниже панели инструментов. Иначе закреплённая внутри iframe нижняя панель окажется вне видимой области внешней страницы.
- Источник визуального решения: Navigation C v1.2, подтверждённый мобильный просмотр 7 ноября 2026 года. Не создавать второй компонент навигации или дубли токенов из `@edem/ui`.
