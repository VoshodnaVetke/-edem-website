# Передача проекта «Эдем» в новый чат

Работай на основе [действующей спецификации v55](DESIGN_SYSTEM_V55.md) и [HTML-эталона v55](../design-system/v55/edem-interface-cyberpunk-v55-onest.html).

Историческая утверждённая графическая основа — v50. Все типы загрузок v50 сохраняются. На мобильном карточки начинают рисоваться заранее (~240 px до экрана) и touch не вызывает ложный ACCESS GRANTED.

Шрифты: Tektur для заголовков, Onest 450 для основного текста (17 px на мобильном), Anonymous Pro для технических меток. Не заменяй утверждённые эффекты и геометрию, не выдумывай мир и не публикуй закрытый лор.

v55 — дизайн-система, а не готовая главная страница сайта.
