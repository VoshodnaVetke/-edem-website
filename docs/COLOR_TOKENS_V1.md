# ЭДЕМ | Color Tokens v1.0 — систематизация утверждённой палитры

**Дата:** 28 октября 2026 года  
**Источник:** утверждённая графическая система v50, действующая спецификация v55 и эталон `edem-interface-cyberpunk-v55-onest.html`.  
**Статус:** базовые значения из раздела «Утверждённые цвета» — APPROVED. Семантическая группировка и имена в CSS — техническая нормализация уже принятых решений; она не утверждает никаких новых цветов. `#1B2230` и `#0B0D12` присутствуют в v55, но являются дополнительными эталонными UI-значениями, а не самостоятельным новым фирменным акцентом.

## 3. Производные эффекты

- `--edem-background-gradient`: радиальный фон **`#0A101A 0% → #05070C 46% → #030509 100%`**. Остановки повторяют эталон v55.
- `--edem-color-ambient-cyan`: `rgb(37 244 255 / 5%)` и `--edem-color-ambient-violet`: `rgb(188 92 255 / 5%)` — технические значения для **слабой фоновой голографии**, согласующиеся с ориентиром около 5% из v55. Это не новые плоские брендовые цвета.
- Подложки карточек могут быть полупрозрачными. **Не закрепляем одну общую прозрачность для всех поверхностей**: в историческом HTML она зависит от типа карточки и эффекта.
- Не задаём в роли общего токена `warning`, `info`, дополнительных зелёных/красных оттенков или инверсной светлой темы: они **не утверждены**.

## 4. Проверка контрастности

Расчётная контрастность по относительной яркости sRGB на непрозрачной базовой карточке `#141923` (для эффектов и прозрачных слоёв требуется отдельная фактическая проверка). Столбец AA — **обычный текст от 4.5:1**.

| Цвет текста | Контраст на `#141923` | AA обычного текста |
|---|---:|---|
| `#FFFFFF` | 17.60:1 | Да |
| `#EAF0FA` | 15.37:1 | Да |
| `#C2CFDF` | 11.13:1 | Да |
| `#AEBBCC` | 9.04:1 | Да |
| `#91A1B6` | 6.69:1 | Да |
| `#25F4FF` | 12.96:1 | Да |
| `#BC5CFF` | 5.12:1 | Да |
| `#7CE7C1` | 11.78:1 | Да |
| `#FF8295` | 7.44:1 | Да |
| `#657080` | 3.51:1 | Нет |

**Выводы:**
- Основной `#EAF0FA` и вторичный `#C2CFDF` пригодны для чтения на базовой тёмной карточке; `#91A1B6` тоже проходит по указанной паре, хотя в дизайне остаётся цветом телеметрии.
- `#BC5CFF` может использоваться как выделение на тёмной карточке, но на изменённых фонах контраст перепроверять.
- `#657080` не достигает 4.5:1 на карточке, поэтому пригоден только для действительно неактивных контролов, не для содержательных пояснений.
- **Нельзя делать белый текст на циановой CTA:** `#FFFFFF` на `#25F4FF` ≈ 1.36:1. Использовать тёмный `#0B0D12` (≈ 14.31:1).
- Состояния ошибки и успеха передавать не только цветом: нужны текст и/или пиктограмма.

## 5. Чего не делать

- Не превращать исторические `--bg: #090C13`, `--text: #F6F8FF`, `--edem-copy: #D5DCE8` в действующие нормативные цвета: они остались в ранних блоках накопленного HTML. В актуальной спецификации **фон `#05070C`, основной текст `#EAF0FA`**.
- Не применять весь циан и фиолетовый как обычные заливки больших блоков: основной объём интерфейса остаётся тёмным.
- Не делать все рамки цветными: утверждены прежде всего белые рукописные контуры с локальными цветными сегментами.
- Не подменять семантические зелёный/розово-красный для статусов фирменными цианом/фиолетовым.
- Не смешивать палитру сайта с отдельной палитрой маскота Евы: это разные системы без отдельного решения об объединении.
