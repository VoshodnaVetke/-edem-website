# Сайт мастерской группы Эдема

`apps/site` — отдельное Next.js-приложение (App Router + TypeScript). Визуальные компоненты, цвета, шрифты и геометрия берутся из общего пакета `@edem/ui`.

## Запуск из корня репозитория

Нужен Node.js >=22.12.

```sh
npm ci
npm run dev:site
```

Адрес разработки: `http://localhost:3000`. Команда сначала собирает пакет UI, затем запускает Next.js.

```sh
npm run build:site
npm run start:site
```

`npm run dev` по-прежнему запускает отдельный каталог UI на `http://localhost:5173`. Корневая команда `npm run build` собирает UI, каталог и сайт. GitHub Actions проверяет оба приложения.

## Общая компоновка и доступность (шаг 3)

- `app/layout.tsx` однократно импортирует `@edem/ui/styles.css`, `@edem/ui/fonts.css` и локальный `app/globals.css`.
- `globals.css` отвечает только за базовую разметку: тёмную схему нативных элементов, box-sizing, типографику body, отзывчивые изображения и клавиатурный фокус. Все цвета, шрифты, размеры текста, сетка и рукописные контуры остаются в `packages/ui`.
- В `styles/page-layout.module.css` находятся только композиционные классы `page`, `section` и `stack`. Интервалы секций задаются `--edem-site-section-space` через `clamp()` без повторного breakpoint; промежутки в `stack` используют библиотечный `--edem-card-gap`.
- Для ограничения ширины используется `Layout` из `@edem/ui`; для сеток — `Grid` или `Gallery`. Не создавайте второй глобальный контейнер и не копируйте переменные UI в сайт.
- `app/layout.tsx` предоставляет единую ссылку пропуска навигации на `#main-content`. Страница должна иметь ровно один `<main id="main-content" tabIndex={-1}>`; не дублируйте ссылку в компонентах страниц.
- Уникальные стили секции размещаются рядом с ней в CSS Modules. CSS не должен содержать `!important` или скрывать ошибки адаптивности через `overflow-x: hidden`. Проверка `npm run check:css` охватывает библиотеку, каталог и сайт; глобальные токены библиотеки запрещено повторно объявлять в приложениях.
- Конфигурации Playwright обоих приложений наследуют общие настройки из корневого `playwright.shared.ts`.
- Проверка сайта: `npm run build:site`, затем `npm run test:site`. `npm run check` проверяет и каталог, и сайт, включая политику CSS.

## Общие компоненты сайта (шаг 4)

- `app/layout.tsx` подключает единственные `SiteHeader` и `SiteFooter` для всех страниц. Ссылка пропуска к `#main-content` остаётся первой в документе.
- `components/layout/SiteHeader.tsx` использует утверждённый `Navigation C` из `@edem/ui`. Отдельных копий мобильного меню, поискового диалога или кнопок нет.
- `components/layout/SiteFooter.tsx` использует существующие `Layout`, `Grid`, `Heading`, `Text` и `SignalDivider`.
- **Согласовано 07.11.2026:** текущая композиция подвала и паттерн навигации C v1.2 (включая закреплённое нижнее меню на телефоне). Утверждённые параметры и границы реализации записаны в `docs/DECISIONS.md`.
- `config/navigation.ts` хранит единственный список **действующих** маршрутов для шапки и подвала. Новые разделы подключаются по мере создания страниц.
- Пока полноценного поиска по содержимому нет, кнопка поиска не выводится. Личный кабинет и заявки не имитируются.
- Главная `app/page.tsx` содержит только проверенную публичную информацию о мастерской группе, без технических демонстраций. Полноценная главная проектируется отдельно.
- Временные `FoundationScreen`, `/demo/shell` и `/demo/shell/preview` удалены из рабочей версии.
- `npm run test:site` проверяет общую оболочку и адаптивность на фактической главной странице.

CMS, БД, авторизация, хостинг и остальные разделы пока не реализованы. Закрытый лор и персональные данные не должны попадать в публичный репозиторий.

## Шаг 5 — маршруты и Figma UX

Работающие публичные маршруты: `/` (главная), `/events` (афиша),
`/games` (архив), `/world` (вселенная), `/wiki` (энциклопедия),
`/order` (заказ игры), `/collaboration` (сотрудничество),
`/about` (о мастерской группе).

Общий `PageShell` отвечает только за семантику страницы, заголовок
и контейнеры, используя существующие `@edem/ui` и
`styles/page-layout.module.css`. Навигация получает работающие маршруты
из `config/navigation.ts`; в нижней мобильной панели закреплены
«Афиша» → `/events`, «Мир» → `/world`, «Энциклопедия» → `/wiki`
с иконками. Меню и подвал ссылаются только на существующие разделы.

`/account`, `/team`, `/contacts` и детали игр/событий/статей
не реализованы. Нет работающего поиска по содержимому, форм отправки,
авторизации или CMS. Тексты разделов — стартовый публичный каркас, а не
утверждённые итоговые материалы. Источник структуры — Figma
`QiELclS9VlG2VduWXNckl1`.
