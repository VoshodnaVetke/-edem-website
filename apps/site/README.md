# Сайт мастерской группы Эдема

`apps/site` — отдельное Next.js-приложение (App Router + TypeScript). Визуальные компоненты, цвета, шрифты и геометрия берутся из общего пакета `@edem/ui`.

## Запуск из корня репозитория

Нужен Node.js >=22.12.

```sh
npm ci
npm run dev:site
```

Адрес разработки: `http://localhost:3000`. Команда сначала собирает пакет UI, затем запускает Next.js.

```sh
npm run build:site
npm run start:site
```

`npm run dev` по-прежнему запускает отдельный каталог UI на `http://localhost:5173`. Корневая команда `npm run build` собирает UI, каталог и сайт. GitHub Actions проверяет оба приложения.

## Границы этого этапа

Главная страница содержит только технический пример подключения. Это не финальная главная и не реализация Figma.

- Глобальный CSS сайта содержит только правила документа; визуальные токены не дублируются.
- Компоненты с клиентской логикой пакета `@edem/ui` подключены внутри клиентского `FoundationScreen`, а корневой layout остаётся серверным.
- CMS, БД, авторизация, хостинг и наполненные страницы пока не подключены.
- Закрытый лор и персональные данные не должны попадать в публичный репозиторий.
