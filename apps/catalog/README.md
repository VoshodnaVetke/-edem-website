# Каталог @edem/ui

Запуск из корня: `npm ci`, затем `npm run dev`. Открыть `http://localhost:5173`.

Каталог показывает 37 актуальных React-примеров, их статусы и код подключения. Поиск и фильтры принадлежат каталогу; сам пакет UI получает содержимое и данные от приложения.

В разработке Vite использует исходники пакета и HMR. Production-сборка и браузерные проверки используют собранный ESM-пакет через его публичные exports.

Команды: `npm run build`, `npm run test:browser`. Текущее API и правила — [packages/ui/README.md](../../packages/ui/README.md).
