# Эдем — инструкции для Codex

Проект: сайт мастерской группы «Эдем» и React-библиотека `@edem/ui`.

До изменений читать README.md, packages/ui/README.md и документацию соответствующего модуля. Актуальные токены и компоненты находятся только в packages/ui/src. Старые HTML-прототипы и дизайн-спецификации удалены по запросу владельца; не восстанавливать их как параллельный источник правил.

- Отчитываться на русском. Владелец может работать с телефона и не обязан писать код.
- Не придумывать факты об играх и мире; не публиковать секреты, реальные данные игроков и закрытый канон.
- Не менять утверждённые логотипы, Еву и другие элементы айдентики без запроса.
- Сохранять геометрию рамок, палитру, типографику и доступность компонентов. Не добавлять каскадные исправления через `!important`.
- Содержимое и состояния операций получает приложение; компоненты не имитируют успешную передачу данных.
- На touch не имитировать desktop-hover. Учитывать reduced motion, клавиатуру и SSR.
- Все подписки, наблюдатели, таймеры и WebGL-ресурсы освобождать при размонтировании.
- Не выбирать CMS, БД, авторизацию и окончательный стек сайта без требований. React для библиотеки уже выбран владельцем.
- Перед отправкой запускать `npm run check`. Форматирование: `npm run format:check`.
- Не заявлять о проверках, которые не выполнялись. Не публиковать пакет в npm и не развёртывать сайт без запроса.
